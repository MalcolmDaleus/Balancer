Balancer is a budgeting web app that allows users to take an active and honest role in their spending habits. The idea was born from a need I saw in my own daily life and the lives of those around me: In a world where spending money is as simple as tapping a card to a reader, it becomes increasingly hard to properly manage one's own finances and properly know the answer to "What did I spend all that money on this month?". The goal was an app that was simple to use and gave instant feedback to promote budgeting habits from the first interaction. The tech stack is Laravel 12 for its extensive backend system made for intricate logic with a React frontend for a clean and appealing look. The root of the app is based in taking in numbers from 5 main budgeting domains: Income, Debt, Spending, Recurring Spending, and Savings Contributions. The app uses a monthly cycle, taking in data provided by the user and displaying it in a balance sheet to see clearly how things add up. The data from these domains is used for several types of calculations that provide the user with real time analysis of their spending habits, and generates a historical report to see their progress over time, with the end goal of saving money. The idea is for the actual data input to be so simple that it becomes a seamless part of the user's daily life, while providing real value to them through pure analysis. When a user taps their card for a coffee, writing it down is as simple as opening up the app, typing in "Coffee" and "$3.45" and allowing the app to incorporate it into the final analysis. The audience is a user conscious of their need for budgeting, but intimidated by keeping track of numbers manually, and committing to a complicated app that makes basic tracking a nightmare. It's simple, but incredibly useful.
